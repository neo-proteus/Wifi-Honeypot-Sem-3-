# LIGHTHOUSE - LEGACY

Lightweight Python Honeypot and Threat Monitoring System

Lighthouse Legacy is a lightweight Python-based honeypot designed to simulate a controlled network service, capture suspicious interactions, and generate security telemetry for analysis.

The project focuses on understanding attacker behavior, network reconnaissance, and basic security monitoring.

Features

* Lightweight honeypot deployment
* Suspicious connection monitoring
* Source IP collection
* Connection and activity logging
* Attacker interaction tracking
* Basic event analysis
* Security telemetry generation
* Lightweight and portable design

Project Domain

Cyber Defense | Honeypots | Threat Monitoring | Network Security

Skills Demonstrated

Python, Honeypots, Network Security, Threat Monitoring, Log Collection, Attack Analysis, Security Monitoring

Purpose

Lighthouse Legacy was developed as a practical cybersecurity project to study how honeypots can be used to attract, observe, and record suspicious network activity in a controlled environment.

The collected telemetry can be used for security analysis and understanding common reconnaissance and intrusion patterns.

Technology Stack

* Python
* Linux
* Networking
* Security Logging
